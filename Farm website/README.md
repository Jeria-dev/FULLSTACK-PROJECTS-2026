Kemboi's Poultry Farm — Static Website

Files
- index.html — main page
- css/styles.css — styles

How to preview
1. Open `index.html` in your browser (double-click or use a local server).

Optional (serve with Python):

```bash
# from the project folder
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Notes
- Images are linked from Unsplash for placeholders. Replace with local images in `assets/` if needed.
- Contact form is static — integrate backend if you need form handling.
